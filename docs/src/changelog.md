# Changelog

See [CHANGELOG.md](https://github.com/josedab/isolate/blob/main/CHANGELOG.md) in the repository for the full changelog.

## [0.1.0] - 2024-12-29

### Added

- Initial release of Isolate sandbox runtime
- Core sandbox execution with Wasmtime 27
- WASI preview1 support
- Capability-based security system
- Resource limit enforcement
- Audit logging
- Prometheus metrics
- OpenTelemetry tracing
- gRPC server
- CLI tool
- Python bindings (experimental)

### Experimental

- GPU sandboxing
- Distributed mesh/clustering
- Enclave/TEE integration
- Hot patching
- Formal verification
- Linux-specific security (seccomp, Landlock)
